# Changelog

## v0.1-draft (2026-09-15)

Initial draft release. 23 jurisdictions, provision-level coding of penalty
structure, scope, enforcement mechanism, and a policy-effect-evidence
registry. **Human verification pass not yet complete** — see
`docs/methodology.md` for what `verification_tier` does and does not mean
at this stage. `enforcement_statistics` is designed but not populated.

Corrections arising from the in-progress human audit will be logged here
as they land, version by version — not applied silently in place.
